# What is this?
It's less of a mod and more a set of collated and new configs and partswitches for various mods, mainly Tantares (+LV, SP & SAF) in the same vein as NFRealism that I've collated over a few years. Some configs will break pre-existing craft files, particularly the rescale patches. Stats have also been tweaked for many Tantares engines so be aware upper stages might be a bit underpowered compared to what you're used to.
Pretty much all of these haven't been made with standard gameplay progression in mind, maybe in future.

**Designed to be downloaded as a whole then unwanted patches removed, since some require the "Kea_configs" file path.**

Most patches have comments explaining what they do.  
Most stats referenced from Realism Overhaul.
